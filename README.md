# 🚀 Soluciones Backend y Modernización de Datos

Bienvenido a mi portafolio de soluciones técnicas. Soy un Desarrollador Backend y Especialista en Bases de Datos enfocado en resolver cuellos de botella operativos para empresas y emprendedores. 

Mi enfoque no es solo escribir código, sino **traducir problemas de negocio en sistemas rápidos, seguros y automatizados.**

## 📂 ¿Qué encontrarás en este repositorio?

### 1. [Migración y Limpieza de Bases de Datos (ETL) ](./1_Migracion_BD)
Ejemplos de cómo extraigo datos de sistemas heredados, Excels desordenados o bases de Access, los limpio utilizando Python (Pandas) y los estructuro en bases de datos relacionales modernas y normalizadas (PostgreSQL / SQL Server).
* **Stack:** Python, Pandas, SQLAlchemy, SQL.

### 2. [APIs de Automatización (FastAPI & WhatsApp)](./2_API_WhatsApp)
Estructura de un Webhook ultrarrápido construido con FastAPI para procesar mensajes entrantes de WhatsApp de forma automática, ideal para bots de atención al cliente y ventas 24/7.
* **Stack:** Python, FastAPI, Uvicorn, Pydantic.
